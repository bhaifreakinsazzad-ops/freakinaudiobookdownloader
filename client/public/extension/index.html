Install the Capture Layer.

SFYTA3.H-V.A Capture Layer provides a quick, least-privilege handoff to the web app. It does not record in the background, bypass DRM, or request broad browser access.

Download extension ZIP

Install in Chrome

  1. Download and unzip the file.
  2. Open chrome://extensions and enable Developer mode.
  3. Select Load unpacked, then choose the unzipped extension folder.
  4. Pin “SFYTA3.H-V.A Capture Layer” and set the web-app URL in its popup.
Rights boundary: Capture still starts only in the visible web app after rights confirmation. The extension is a companion, not a hidden recorder.
