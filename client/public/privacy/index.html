SFYTA3.H-V.A Capture Layer Privacy Policy

Effective date: September 21, 2026 · Version 1.0.0

SFYTA3.H-V.A Capture Layer is a minimal Chrome companion for the SFYTA3.H-V.A Capture Studio. This policy describes the extension’s data practices for the Chrome Web Store and for users.

What the extension stores

The extension stores the web-app URL that a user enters in its popup. It stores this value locally in chrome.storage.local so the popup can remember the selected deployment. The value is used only to prefill the popup and to open that URL after the user explicitly clicks the action button.

What the extension does not collect

The extension does not collect or transmit browsing history, page content, audio, recordings, credentials, authentication tokens, cookies, payment information, health information, or personal identifiers. It does not use analytics, advertising, crash reporting, remote code, content scripts, host permissions, or network interception.

Sharing and sale

The extension does not sell, share, or transmit the stored URL or any other extension data to the developer or third parties. No external API is called by the extension.

Permissions

The only requested permission is storage. It is required to save the user-entered web-app URL locally. The toolbar action and service worker are extension platform components, not access to website content.

Retention and deletion

The stored URL remains until the user changes it, clears extension storage in Chrome, or uninstalls the extension. Uninstalling the extension removes its local storage according to Chrome’s extension storage behavior.

Capture and rights boundary

The extension does not record audio in the background. Audio capture, rights confirmation, protected-source checks, and visible browser permission prompts remain inside the SFYTA3.H-V.A web application. The extension does not bypass DRM or access controls.

Changes

If the extension’s data practices change, this policy and the Chrome Web Store privacy disclosures will be updated before the changed release is submitted.
